# Чат-лаборатория — чат-бот с ограничителями ответа

Интерактивная версия дня 2 в формате чата: слева — панель настроек,
справа — диалог с полем ввода. Для каждого сообщения можно включить
ограничители из задания — формат, длину, условие завершения — и выбрать
механизм: просьба словами в промпте или гарантия параметром на API.

## Настройки (применяются к конкретному сообщению)

- **Формат ответа** — JSON или Markdown; механизмы: инструкция в промпте или
  `response_format: {"type": "json_object"}` на API (только для JSON).
- **Длина ответа** — «не более N слов» в промпте или `max_tokens` на API.
- **Условие завершения** — stop-последовательность (`\n`, `\t` пишутся как escape);
  на API передаётся как `stop: [...]`, в промпт добавляется просьба закончить перед ней.
- **Модель** — `glm-4.6` (thinking disabled — ограничения действуют на видимый ответ)
  или `glm-5.3` («всегда думает»: `max_tokens` и `stop` могут сработать на скрытых
  рассуждениях, видимый ответ придёт пустым — находка дня 2 в один клик).
- **temperature** — по умолчанию 0, как в дне 2.

## Память диалога

Вся история переписки передаётся модели целиком, поэтому каждый следующий
ответ учитывает предыдущие запросы; «новый чат» историю сбрасывает.
Настройки «прилипают» к отправленному сообщению: над каждым запросом показаны
бейджи выбранных ограничений (жёлтые — промпт, синие — API), под ответом —
`finish_reason`, токены, слова, латентность и раскрывающийся блок «что ушло
в модель» с фактическим промптом и параметрами. Инструкции дописываются
к каждой пользовательской реплике по её собственным настройкам.

## Запуск

Фронтенд — React (Vite), собранные файлы коммитятся в `lab/frontend/dist/`,
поэтому для работы сайта Node не нужен:

```bash
cp .env.example .env   # и вписать свой GLM_API_KEY, если ещё нет
.venv/bin/python lab/server.py
```

Ключ берётся из `.env` в корне репозитория (`GLM_API_KEY`); API — Z.ai,
совместимый с OpenAI SDK. Открыть <http://127.0.0.1:7861> (в WSL2 — по
eth0-IP: `0.0.0.0` уже прописан). Серверу, кроме `openai`, ничего не нужно:
он на стандартной библиотеке Python.

Маршруты: `/` — чат, `/day2` — замороженная страница дня 2 (в шапке лаборатории
ссылка на неё называется «выводы»), `POST /api/chat` — диалог (NDJSON-поток:
`start` → `delta`… → `done` с метаданными). Ответы стримятся в браузер по мере
генерации; кнопка «стоп» обрывает запрос, одновременно обрабатывается один
запрос (409, пока занято).

## Стек и дизайн

Фронтенд — React 19 + Vite; дизайн — по протоколу
[minimalist-ui / taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT).

## Пересборка фронтенда

Нужен Node 20.19+ / 22.12+ (здесь — тарболл в `~/.local/opt`, симлинки в `~/.local/bin`):

```bash
cd lab/frontend
npm install        # один раз
npm run build      # соберёт dist/, сервер отдаёт его как есть
npm run dev        # режим разработки: :5173 с прокси /api и /day2 на :7861
```

## Что считается автоматически

Для каждого ответа, как в дне 2: слова, токены, валидность JSON,
`finish_reason`, латентность; пустой ответ `glm-5.3` (токены ушли в скрытые
рассуждения) помечается подсказкой.
