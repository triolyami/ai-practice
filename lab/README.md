# Лаборатория — та же матрица прогонов, но на вашем промпте

Интерактивная версия дня 2. Вводите любой запрос, включаете/настраиваете ограничители —
и смотрите, как семь вариантов одного запроса (эталон + три пары «промпт против API»)
уходят в модель параллельно, а ответы приходят в браузер по мере готовности.

## Что можно менять

- **Промпт** — любой текст вместо «Расскажи, как устроен интернет».
- **Модель** — `glm-4.6` (thinking disabled, ограничения действуют на видимый ответ)
  или `glm-5.3` («всегда думает»: `max_tokens` и `stop` могут сработать на скрытых
  рассуждениях, видимый ответ придёт пустым — находка дня 2 в один клик).
- **Формат** — текст инструкции (она идёт и в «промпт»-вариант, и в пару с
  `response_format: json_object`).
- **Длина** — лимит слов в промпте (шаблон с `{n}`) и `max_tokens` для API-варианта.
- **Условие завершения** — stop-последовательность (`\n`, `\t` пишутся как escape)
  и инструкция для «промпт»-варианта.
- **temperature** — по умолчанию 0, как в дне 2.

Каждый ограничитель можно выключить — тогда пары просто не отправляются
(1, 3, 5 или 7 прогонов). По завершении кнопка «Скачать results.json» отдаёт
результаты в том же формате, что и день 2.

## Запуск

```bash
cp .env.example .env   # и вписать свой GLM_API_KEY (если ещё нет)
.venv/bin/python lab/server.py
```

Открыть <http://127.0.0.1:7861> (в WSL2 — по eth0-IP: `0.0.0.0` уже прописан).
Зависимостей, кроме `openai`, не нужно: сервер — стандартная библиотека Python.

Маршруты: `/` — лаборатория, `/day2` — замороженная страница дня 2,
`POST /api/run` — прогон (NDJSON-поток: `start` → `result`… → `done`).

## Что считается автоматически

Для каждого ответа — как в дне 2: слова, токены, абзацы, валидность JSON,
markdown-ограждения, `finish_reason`, латентность. Плюс две мелочи для сравнения:
совпадение начала `stop-api` с эталоном (посимвольно) и индикация пустого ответа,
когда токены ушли в скрытые рассуждения.
