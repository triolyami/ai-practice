# День 5 — версии моделей

Один и тот же запрос на трёх уровнях линейки Z.ai: слабая `glm-4.5-flash`
(бесплатная), средняя `glm-4.6`, сильная `glm-5.3` (всегда думает, здесь
`effort: low`). Замеряются время до первого токена, полная латентность, токены
и стоимость; качество оценивает судья `glm-5.3` вслепую (ответы обезличены
до A/B/C, порядок чередуется).

Есть две части:

- **Живой стенд** — свой промпт, выбор моделей, стриминг ответов и судья
  по кнопке: `.venv/bin/python day5/server.py` → `http://127.0.0.1:7864/`
  (замороженная страница ниже доступна оттуда же по ссылке «замороженный
  прогон»);
- **Замороженная страница** `day5/index.html` (открывается через file://) —
  прогон 3 запроса × 3 модели × 3 попытки с выводами и ценами.

## Живой стенд

```bash
.venv/bin/python day5/server.py            # :7864, фронт собран в day5/frontend/dist
cd day5/frontend && npm install && npm run build   # пересборка фронта (dev: npm run dev, :5176)
```

Промпт вводится в поле, модели выбираются чипами (можно любые), прогоны идут
параллельно. «спросить судью» активно от двух готовых ответов: судья `glm-5.3`
видит ответы обезличенными (A/B/C, порядок перемешан) и рядом с каждым — время,
токены и стоимость; качество важнее, при равном качестве предпочтение отдаётся
более дешёвому или быстрому. Новый прогон сбрасывает устаревший вердикт.
Состояние (промпт, выбор, готовые ответы, вердикт) живёт в localStorage
`day5-state-v1`.

## Замороженный прогон

```bash
cp .env.example .env        # один раз, вписать GLM_API_KEY
.venv/bin/python day5/experiment.py               # прогон + страница
.venv/bin/python day5/experiment.py --render-only # пересобрать страницу без API
.venv/bin/python day5/experiment.py --no-judge    # без судейства
```

Единственное место для правки промптов замороженного прогона —
`day5/prompts.py`, список `REQUESTS`: каждый элемент `{id, title, prompt}`.
После правки просто запустить `experiment.py` заново — `results.json` и
`index.html` перезапишутся. Оценки судьи при желании правятся руками в
`results.json` (поля `score`, `comment`) с последующим `--render-only`.

## Что меряется

- `ttft_ms` — время до первого токена (стриминг);
- `latency_ms` — полное время ответа;
- `prompt_tokens` / `completion_tokens` — из usage финального чанка;
- `cost_usd = (in × price_in + out × price_out) / 1e6`; кэш-цены не
  применялись — прогоны одиночные;
- 3 прогона на модель, `temperature 0`, без `max_tokens` (у 5.3 скрытые
  рассуждения съедают лимит — см. день 2); страница считает медианы сама.
