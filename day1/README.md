# LLM Chat — домашнее задание 1

Минимальный код, который отправляет запрос в LLM через API, получает ответ и выводит его в консоль или простой веб-интерфейс.

## Структура проекта

| Файл | Назначение |
|---|---|
| `config.py` | Загружает `.env`, создаёт клиент OpenAI SDK для Z.ai, функция `ask()` (поддерживает историю диалога) |
| `chat.py` | CLI-версия: чат в консоли |
| `web.py` | Веб-версия: чат-интерфейс на Gradio |
| `.env.example` | Шаблон файла с переменными окружения |

Модель: `glm-5.3` (Z.ai), API совместим с OpenAI SDK.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Настройка ключа

Получите API-ключ на https://z.ai, затем создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
# и впишите свой ключ в .env:
# GLM_API_KEY=ваш-ключ
```

Ключ хранится только локально — `.env` добавлен в `.gitignore` и не попадает в репозиторий.

## Запуск

CLI-версия (чат в консоли, для выхода введите `exit`):

```bash
.venv/bin/python chat.py
```

Веб-версия (откроется на http://127.0.0.1:7860):

```bash
.venv/bin/python web.py
```

## Как это работает

1. `OpenAI` SDK отправляет POST-запрос на `https://api.z.ai/api/paas/v4/chat/completions` с текстом пользователя и моделью `glm-5.3`
2. API возвращает ответ модели в JSON
3. Ответ выводится в консоль (`chat.py`) или в веб-интерфейс (`web.py`)

Каждый запрос к API не сохраняет состояние: чтобы модель «помнила» диалог, вся история пересылается в каждом запросе (в `web.py` это делает Gradio автоматически).
