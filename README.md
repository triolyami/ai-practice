# AI Practice — домашние задания курса

Репозиторий с домашними заданиями курса по AI-инженерии. Каждое задание живёт в своей папке.

| Папка | Задание |
|---|---|
| [`day1/`](day1/) | Запрос к LLM через API: чат в консоли и в веб-интерфейсе (Gradio) |
| [`day2/`](day2/) | Управление ответом модели: формат, длина, условие завершения |
| [`lab/`](lab/) | Чат-лаборатория: ограничители дня 2 (формат, длина, условие завершения) на любое сообщение диалога — промптом или параметром API |
| [`day3/`](day3/) | Разные способы рассуждения: одна задача решается через API четырьмя способами (+2 доп. эксперимента), сравнение ответов с эталоном |

API — Z.ai, совместим с OpenAI SDK; модели: `glm-5.3` в day1, `glm-4.6` (по умолчанию) и `glm-5.3` в day2, lab и day3. Ключ хранится в `.env` в корне репозитория (не коммитится) — шаблон: `.env.example`.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
# впишите свой ключ в .env: GLM_API_KEY=ваш-ключ
```

Подробности по каждому заданию — в README внутри его папки.
