# День 4 — Температура

Один и тот же запрос в нескольких температурных точках (по умолчанию 0 / 0.7 /
максимум модели — значения редактируются) — сравнение точности, креативности и
разнообразия. Живой плейграунд: «дорожки» по температурам, N прогонов в каждой,
прогоны идут параллельно (до 4 одновременно), стриминг ответов, бейджи проверки
фактов, индикаторы детерминированности (t=0) и разнообразия (средняя близость
Жаккара между прогонами). Для glm-5.3 выбирается effort рассуждения
(low/high/max). При первом открытии страница загружает замороженные прогоны из
`results.json`, любой прогон можно перезапустить вживую.

## Запуск

```bash
.venv/bin/python day4/server.py      # http://127.0.0.1:7863 (из Windows — eth0-IP)
```

Фронтенд уже собран в `day4/frontend/dist/`, Node не нужен. Для разработки:
`cd day4/frontend && npm install && npm run dev` (:5175, прокси на :7863).

## Файлы

- `config.py` — клиент Z.ai, `MODELS` (glm-4.6 → thinking disabled, glm-5.3 →
  thinking effort), `EFFORTS`/`DEFAULT_EFFORT`, `thinking_config(model, effort)`.
- `defaults.py` — дефолтный промпт (нейминг кофейни + два проверяемых факта),
  ожидаемые факты, температуры по умолчанию.
- `server.py` — stdlib-сервер :7863, `POST /api/run {prompt, model, temperature,
  effort}` (NDJSON `start`/`delta`/`done`), temperature 0–2 (не клампится —
  ошибка API видна в карточке), effort только для glm-5.3 (иначе low), параллельные
  генерации без блокировок, обрыв соединения прерывает свою генерацию.
- `run_matrix.py` — замороженный прогон: обе модели × 3 температуры × 3 прогона
  → `results.json`. Перезапись безопасна: выводы живут в коде фронтенда, а не в json.
- `frontend/` — Vite + React; `dist/` закоммичен. Прогоны идут параллельно
  (пул на 4, `MAX_PARALLEL` в `constants.js`, «остановить» снимает все);
  температуры редактируются по каждой модели (1–4 точки, дубли склеиваются,
  некорректные подсвечиваются, значения > 1 для glm-4.6 предупреждают) и
  сохраняются в localStorage вместе с effort.

## Что выяснилось (полные выводы — на странице)

- **glm-4.6 отклоняет temperature > 1** (ошибка 1210 «диапазон [0,1]»), поэтому
  его третий прогон идёт при 1.0; задание с 1.2 выполнено на glm-5.3.
- **t=0 не даёт дословного повтора**: у glm-4.6 из трёх прогонов два совпали
  байт-в-байт, третий отличился формулировками; у glm-5.3 все три разные —
  скрытое рассуждение сэмплируется всегда.
- Точность на тривиальных фактах не деградировала ни в одном из 18 прогонов.
- Разнообразие: t=0 — одни и те же названия у glm-4.6; 0.7 — новые, но
  «безопасные»; 1.0 — смелые и странные. У always-thinking glm-5.3 разнообразие
  идёт из рассуждения, температура меняет в основном поверхность ответа.
