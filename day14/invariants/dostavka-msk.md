# Доставка по Москве — бизнес-правила

## География
- зона доставки: только Москва в пределах МКАД
- другие города: не обслуживаются; предлагать выход за пределы зоны нельзя

## Стек и ограничения
- api: только бесплатные публичные API или собственные сервисы
- платные сервисы: Google Maps, платные геокодеры и платёжные агрегаторы запрещены
- бэкенд: Python + FastAPI

- бан: (?i)санкт-петербург|питер|\bспб\b|новосибирск|казань|екатеринбург
- бан: (?i)google maps|yandex maps|2gis|mapbox
- бан-код: (?i)stripe|paypal|cloudpayments|yookassa
